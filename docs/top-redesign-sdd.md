# トップページ改修 SDD

更新日: 2026-10-18 / 版: 2.3 / 状態: GitHub main・erinui.comへ公開済み。ローカル/Linux各177試験合格。本番確認と残件は第14節を参照

PCでは左側のマップを表示したまま右側のおすすめ情報を読み、SPではマップからおすすめへ縦に進む構成へ変更する。マップの6スポットは直接のページ遷移から、対応レコメンドへのページ内移動に変更する。既存素材・書体・コンテンツURL・データ更新・軽量配信を引き継ぐ。

本書を仕様駆動開発の入口とし、要件、現状との差分、改修単位、受入条件を管理する。デザインの考え方は[デザイン設計書](top-redesign-design-spec.md)、寸法・DOM・状態・実装契約は[詳細設計書](top-redesign-detail-spec.md)を参照する。2.2までの資料整備・2.3の実装・公開確認を履歴として分離する。

## 2. 対象と保持条件

対象はTOPのレイアウト、マップの導線、案内、7枠のカードとカルーセル、見出し、背景、TOPのナビ・フッターの整合。下層ページの再デザイン、ゲーム本体、API・収集処理の仕様変更は含めない。第12節の利用者指示により、今回の工程にはGitHub・本番への公開と公開確認を含める。

既存のキャラクター・建物・サムネイル・ロゴを使用し、新しいキャラクターやイラストは生成しない。テキストはHTML/Figma TEXTで保持する。Figmaの画像レイヤーへの直接反応に対応するWeb実装は、既存の `a.map-card > img` を利用する。HTMLの画像へクリックイベントだけを付ける方式には置き換えない。

## 4. 基準画面と操作契約

PC1440×900はヘッダー72、左730.7／右709.3、マップ490.7×780、上下24px。右はサイト見出し92＋案内168＋ニュース544で、ニュース下端876px、残り24pxを基準にする。1366×768・1280×720では案内と余白を短縮し、通常倍率でニュースを初期表示内へ収める。文字拡大・フォント読込・長文で収まらない場合は内容の表示を優先する。

SP390×844はヘッダー64、サイト見出し96、マップ幅342、その下にニュース→キャラクター紹介→ゲーム→YouTube→ブログ→グッズ→LINEスタンプ→フッター。マップは固定しない。PC/SP別々の本文DOMを作らず、表示を切り替えても地図の建造物を並べ替えない。

| 画像・スポット | Webの採用先 | 種別 |
| --- | --- | --- |
| ゲーム | #game-title | ページ内 |
| キャラクター紹介 | #character-title | ページ内 |
| YouTube | #youtube-title | ページ内。背景・サムネイル/統計・看板の3層は1リンクに内包 |
| ブログ | #blog-title | ページ内 |
| グッズ | #goods-title | ページ内 |

| X | https://x.com/erikanuinui | 別タブ、noopener noreferrer |

マップの到着見出しは固定ヘッダーに隠さない。アンカーはJS無効でも機能し、JS補助はフォーカス・動き低減・連続操作を担当する。カードは既存の詳細・外部コンテンツへの実リンクを維持する。ナビ「おしらせ」は既存の `pages/blog.html` のままとし、ニュースへの変更は別判断とする。
