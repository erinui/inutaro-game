### メタデータの採用

TOPは `エリカッテシティ | erinui`、OGP/TwitterのTOP見出しはサイト名のみ。下層は「ページ名 | エリカッテシティ」、ゲーム一覧は `ぬいんてんどう ゲーム一覧 | エリカッテシティ`。`og:site_name` は運営者ではなく表示上のサイト名として全7ページで新名称へ統一。descriptionは自サイト名を含む箇所だけ変更し、運営者を指すerinui/えりぬいは保持する。URL・OGP画像は保持する。

### 書体の採用

JP同梱説明画像にSIL OFL1.1の明記がある。Web利用条件は[OFL公式FAQ](https://openfontlicense.org/ofl-faq/)のWeb配信・WOFF変換条件を確認する。元TTFの内部名・メタデータ・文字データを保持し、形式圧縮のみのwoff2を使用する。旧フォントは削除せず保管する。S07は今回の文言改修対象外であり、ゲームの専用CSS/preloadを変更しない。

## 実装順序

1. 確定原稿・メタデータ・保留範囲を本資料とJSONへ固定。
2. 文言/素材/参照/保持の受入テストを追加し、変更前の失敗を記録（Red）。
3. 書体、HTML原稿・メタデータ、道路文字を反映。既存自然レイアウトで検証し、必要な局所CSSだけ調整（Green）。
4. 12幅の回帰試験、操作試験、PC/SP目視。実装済み/保留/未検証を資料へ記録。
5. 無関係な整理やFigmaの画面移動は実施しない。GitHub公開は別の指示まで実施しない。

## 実行方法

テストはNode標準テストランナーと既存環境のPlaywright/XMLパーサーを使用する。依存パッケージが外部ランタイムにある場合は `NODE_PATH` にnode_modulesを指定する。Chromium未同梱環境では `CHROME_EXECUTABLE` を指定できる。

検証環境: Node v25.8.2、Playwright 1.62.1、xml-js 1.6.11、MacのGoogle Chrome。フォント変換/照合はFontTools、画像の確認用切り出しはSharpを使用。リポジトリに依存パッケージやブラウザバイナリを複製しない。

```bash
node --test tests/site-design.test.mjs
node scripts/check-site-design-layout.mjs
```

ブラウザ試験はローカルの限定公開ファイルだけを配信する。`.env`、Git、設定や履歴ファイルを公開しない。外部へのフォーム送信、APIの更新、GitHub反映は行わない。

ローカル確認は `node scripts/preview-site.mjs` で起動し、表示された127.0.0.1のURLを使う。テストとプレビューの配信範囲は同一。終了はCtrl+C。

### 実装上の判断

- JP元TTFは配布ファイルと同一SHA-256。woff2は形式圧縮のみで追加し、元ファイルと旧書体は削除していない。
- WOFF2往復検証でcmap、全10,222 glyph、nameを含む21テーブルを照合。`head`のチェックサム調整値とWOFF2輸送時に立つbit11のみ比較対象外とし、文字データ差は0件。ファイルサイズはTTF 3,258,000bytes、WOFF2 1,635,088bytes。
- 道路文字は最新Figmaから読み取り専用でSVG出力し、既存背景座標へ正規化。地面・道路・マスク・viewBoxを構造比較で保持した。配信SVGはアウトライン、Figma原本はTEXTのまま。
- TOP SP H1は47.5px、374px以下だけ38px。ガイド見出しはPC36px/SP28px。プライバシーSP H1はFigmaの37.25pxへ局所調整した。本文・他ページH1・カード寸法の一括変更は行っていない。ユーザー調整済みX画像と位置/サイズを保持した。
- ナビの「おしらせ」は既存note案内を指すため保持。TOP「ニュース」と未確定の「業務連絡」を混同しない。
