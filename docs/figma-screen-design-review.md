## 指摘事項

### R1 / P2: 内容別のレイヤー構造が不足している

[S01-PC](https://www.figma.com/design/XEgScjFWiQZTUZcnbn24RO/?node-id=2239-52958)では、`Browser layout / fixed source coordinates`直下に199レイヤーが並ぶ。オリジンに関するものだけでも`character-inutaro-origin / GROUP`が29件あり、画像・名前・本文・タグの区別が名前から付かない。

[S07-PC-G02](https://www.figma.com/design/XEgScjFWiQZTUZcnbn24RO/?node-id=2239-68974)でも`Game / Canvas + HTML UI / GROUP`が51件ある。描画の再現はできているが、説明パネル・HUD・ボタンなどを特定して選択しにくい。方法書の「ヘッダー、本文、カード、画像等で命名する」という意図に対し、内容別の識別が不十分。

推奨方針: 表示座標・重なり・マスク・rootIdを維持したまま、画像、タイトル、本文、タグ、HUD、説明パネル、操作ボタン等の役割を命名する。安全にまとめられる範囲だけグループ化し、整理前後のPNG一致を必須にする。文字のアウトライン採用自体や、コンポーネント未導入は今回の不具合とはしない。

### R2 / P3: ゲーム一覧の背景ストライプが実表示よりぼやける

[S02-PC](https://www.figma.com/design/XEgScjFWiQZTUZcnbn24RO/?node-id=2239-59476)のゲームカード画像部で、ブラウザでは明瞭な斜線境界がFigmaでは柔らかくなる。等倍のカード比較と、x=270、y=462の96×96px領域を4倍にした比較で確認した。文字輪郭だけのアンチエイリアス差とは分けて扱う。

元の表現は`home.css`の`repeating-linear-gradient`。変換・画像補間に起因する可能性があるが、どの変換段階で劣化したかは本レビューでは未確定。配置・文言を損なうものではなく、軽微な再現品質の差。

推奨方針: 中間SVGとFigmaの画像解像度・倍率・補間を追跡し、この背景だけ図形で再現するか、実寸に十分な解像度の背景画像へ置き換える。線幅・角度・色は実装を維持し、カード全体の再デザインは行わない。
