# 検索結果用アイコンの統一 SDD実施仕様

作成日・最終更新: 2026-10-11 / 状態: 実装・機能回帰完了、公開確認待ち

既存の犬タローゲーム画像をサイト共通の検索用アイコンとして維持し、公開8ページの指定を統一する。GitHub反映と本番確認まで利用者承認済み。検索結果で表示されること自体はGoogle側の判断であり、実装の合否とは分ける。

## 1. 現状と変更境界

- 基準コミット: `645f972c78e66f7df750566dd16416cac3da91a9`。
- TOP、ゲーム一覧、ゲーム本体には32px favicon、180px Apple用、192pxアイコンを指定済み。下層5ページは32pxのみ。
- 本番TOPと3画像はHTTP 200、PNG実寸は32×32、180×180、192×192。robots.txtはクロールを禁止せず、本番応答にnoindexはない。これは通常HTTPの確認であり、Googlebotの実アクセスログ確認ではない。
- Google向け192px素材はすでに存在する。32pxも最低条件を満たすため、非表示原因をサイズ不足・指定漏れと断定しない。
- 通常デザイン、文面、タイトル/description、構造化データ、OGP、CSS、JS、マップ、ゲーム、取得周期・データは変更しない。外部プロフィール編集・新規ログイン・DNS変更・圧縮は対象外。

## 2. 採用仕様 SEO FAVICON 01

全8ページで以下3指定を初期HTMLのheadに各1件置く。相対パスの階層を維持し、HTTPローカル・fileプレビュー・GitHub Pagesのサブパスでも同じ資産へ解決する。

| rel | sizes | ファイル |
| --- | --- | --- |
| icon | 32x32 | `assets/favicon.png?v=20260616-icon` |
| apple-touch-icon | 180x180 | `assets/apple-touch-icon.png?v=20260616-icon` |
| icon | 192x192 | `assets/icon-192.png?v=20260616-icon` |

下層5HTMLに180pxと192pxの2行だけを追加する。TOPとゲーム2HTMLは変更しない。3画像は既存のバイト列を流用し、生成・拡大・描き直しはしない。既存クエリも固定値のまま保持し、無用なURL変更を避ける。ブラウザやGoogleがどの候補を選択するかは保証しない。

`/favicon.ico` の新設、web manifest、Organization構造化データ追加は今回不要。明示したPNGリンクで要件を満たし、公開allowlistを拡張しない。

## 3. SDDとTDDの実装手順

| 段階 | 作業 | 次段階の条件 |
| --- | --- | --- |
| 0 | 変更前8HTML・3画像のSHA、headの限定差分をmanifestへ記録 | 既存基準を上書きせず対象が明確 |
| 1 | JS無効の初期HTML、PNG実寸/HTTP、参照解決、全HTML逆変換の試験を追加 | 下層の不足で意図したRedを確認 |
| 2 | 下層5HTMLへ2指定を追加 | 新規試験Green。body・他のhead・画像はSHA保持 |
| 3 | 既存95ケースと新規ケース、公開ビルド、通常画面保持を確認 | 保護試験を緩めず全件合格、公開混入なし |
| 4 | 最新mainの生成データを保持して取り込み、限定stage・commit・push | Cloudflare/GitHub Pages成功、本番8HTMLと3画像照合 |
| 5 | TOPのGoogle再取得を依頼し、受付と実際の検索アイコン表示を分けて記録 | 利用可能な本人のSearch Consoleで受付確認。認証が必要なら本人操作へ引き継ぐ |

変更manifestは `tests/fixtures/seo-favicon-changes.json`。ファイル・変更前/後の正確なコード片・件数を登録する。既存保護試験ではこの差分だけを先に逆変換してから、信頼性改修とSEO改修の逆変換を行う。関数やhead全体を検査除外にしない。自動生成データは別の生成コミットとSHAを記録する。

## 4. 受け入れケース

| ケース | 検証 |
| --- | --- |
| F01（8ページ） | JS無効でheadに3指定、重複なし、正しい相対パス。HTTP取得できPNG実寸がsizesと一致 |
| F02 | 3画像のSHAが変更前と一致。192pxは正方形、既存ゲーム画像を保持 |
| F03 | 本番の正規URL/HTML URL、ローカル、GitHubのサブパス、fileプレビューで全参照が同じ資産へ解決 |
| F04 | 全8HTMLの承認差分を逆変換すると変更前SHAと一致。本文・他headの変更なし |
| F05 | 新規の空出力へ公開ビルド。8HTML・3画像が一致、資料・試験・未追跡素材を含まない |

通常画面は固定データ・時刻・フォント・画像完了・同一viewportで変更前後を比較する。ゲームはゲーム専用の表示と操作を既存回帰試験で確認する。アイコン変更だけを理由にSafari自動操作やVoiceOverの設定を再度有効化しない。

## 5. 公開後と残件

- Googleはサイトのホスト名単位でアイコンを扱う。ホームページと画像の再クロールが必要で、数日〜数週間かかる場合がある。全要件を満たしても検索結果表示は保証されない。[Google公式仕様](https://developers.google.com/search/docs/appearance/favicon-in-search?hl=ja)
- 再クロール依頼の受付は「検索結果での表示確認」と同義ではない。アイコン未反映だけを理由にURLを頻繁に変更しない。
- 前回未登録だった3URL、主要語の検索実績、実ユーザー性能の経過確認は別管理。外部プロフィールは本人ログイン待ち、画像・フォント圧縮は保留、VoiceOver音声内容の未確認も保持する。
- 復元は今回追加したheadの2行を対象とする。正常な生成データ、画像、他の承認済み改修を巻き戻さない。

## 6. 実施記録

### ローカル実装・検証

- Red: 新規12ケース中5合格・7失敗。下層の180/192px指定不足と、それに依存する参照・逆変換試験の失敗を確認した。
- Green: 下層5HTMLへ各2行を追加し、新規12/12、既存95と合わせた統合107/107合格。既存基準や検査除外は拡張していない。
- レイアウト: 12幅×7ページの84ケース合格。公開ビルドは86ファイル、資料・試験・未追跡素材の混入なし。
- 変更前8HTMLを正確な承認差分だけ逆変換したSHAは全件一致。3アイコン画像のSHAも一致。本文・CSS・JSの変更はない。
- ピクセル比較は完全一致を確認できなかった。最終試行では12ケースが差分0、その後の390px利用規約画面でロゴ画像内89ピクセルに差分があり停止。別試行では1440pxのロゴ内93ピクセルにも差分があった。これは合格として集計しない。
- 独立Chromeでの対照撮影は、イラスト画面4枚、利用規約画面6枚の変更前同士・変更後同士・前後比較で差分0。描画経路・撮影条件の影響が疑われるが原因は断定できず、全21画面のピクセル完全一致は未確認として残す。試験的な待機・ブラウザ分離の変更は採用せず、元の検証スクリプトを保持した。
- 通常画面のソース完全一致とレイアウト試験を根拠に公開へ進む。ピクセル未確認点は保持し、公開後にPC/SPの通常表示を目視確認する。Safari自動化・VoiceOverの設定は変更していない。
