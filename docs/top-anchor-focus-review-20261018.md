# TOP到着見出しの青枠撤去と追加表示の確認

日付: 2026-10-18

## 原因と修正

本番 `e3ccd38` でゲームのマップリンクをクリックし、移動先のH2に `outline: rgb(22, 100, 168) solid 3px` が現れることを再現した。`:focus-visible` がfalseでも表示されていた。これは実装側で `.section-title:focus` をリンク・ボタンのfocus-visibleと同じ指定にしたためで、利用者が指定したデザインではない。

`home.css` の対象指定を分離し、到着見出しのoutlineをnoneにした。ブラウザ標準の輪郭が代わりに出ないよう、単なるセレクター削除ではなく明示的に抑止する。黒い3pxの見出しボーダー、4px/5pxの影、黄色の背景、到着座標は変更しない。`home.js` の見出しへのフォーカス移動は、読み上げと次のTab操作の開始位置のため維持する。

公開用CSSは `assets/versioned/home.f0e0ec9f21efc909.css` へ再生成した。旧ハッシュ資産は削除しない。承認差分記録の変更対象は `home.css` と資産manifestのみで、旧baselineは取り直していない。

## ほかの追加表示の棚卸し

前回改修前の `97ba5f0` と現行ソースのHTML/CSS/JS差分、設計書、本番と修正後ビルドを確認した。

| 表示 | 判定・対応 |
| --- | --- |
| 到着見出しの青い輪郭 | 指定外の補助表示。今回撤去 |
| リンク・ボタンの青いfocus-visible | 前回実装で明示的に追加したキーボードの操作位置表示。見出しとは分離して維持。クリック時には表示されないことを確認 |
| ナビ・「すべて見る」のホバー下線 | リンクを判別するための表示。前回改修の採用内容として維持 |
| 6枠の「すべて見る」とSPカルーセル矢印 | SDDで採用した導線・操作要素。維持 |
| PCの案内吹き出しと犬タロー、背景市松・波形・共通見出し | 前回採用したデザイン。維持 |
| ニュースの分類色 | 前回採用したGAME/YOUTUBE/NOTE/SUZURI/LINEの分類表示。通常カテゴリ枠へ重複ラベルは追加していない |
| ゲームのNEXT・準備中、AND MORE | 改修前から存在する内容で、新規追加ではない。維持 |
| マップ選択の常設ラベル、ホバー用色面・囲い、追加ツールチップ | 今回の差分に実装なし。対象クラスへの追加選択状態や `:target` の新しい表示指定もなし |

今回の実装変更は見出しのoutlineに限定。上記以外の要素を新たに削除・再設計していない。
