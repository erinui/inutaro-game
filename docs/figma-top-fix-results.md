## 対応範囲

レビューR1〜R5を対象に実装・Figmaを修正した。既存のユーザー調整（X画像・配置）、文言、外部データ、PCのカード幅は変更していない。GitHubへの公開は未実施。

| ID | 改善点 | 修正・確認結果 |
| --- | --- | --- |
| R1 | SPカード右端・影のクリップ、次カードが見えない | `home.css`の幅基準を`84vw`から親幅の`84%`へ変更し、`min-width: 0`を明示。7幅でカードと影の収まりを検証 |
| R2 | Figmaのカルーセル末尾が途中状態 | 最大スクロール位置への到達を待って撮影。PC YouTubeは4本目・5本目・AND MOREが全体表示され、次ボタンは無効 |
| R3 | さすけ復路が反転前 | クリック後のクラス生成を待ち、対象アニメーションだけを1200msへ設定。復路の左右反転を確認 |
| R4 | Figmaの円・影が薄い | 白色アルファへ変換済みのSVGマスクがFigmaではLUMINANCEとして取り込まれていた。該当マスクをALPHAへ変更。PCの指摘3色はRGB値まで一致 |
| R5 | SPのゲーム以降が約1px上へずれる | 全要素の計算済み幅・高さを固定する処理を撤去。書体サイズのみ固定して再取り込み。主要9見出しはPC/SPともX/Y補正0pxで最も一致 |

R4では元サイトの色・影を変更していない。半透明画像を輝度マスクとして処理する取り込み結果が濃度差の原因だった。輪郭の補間差までゼロになったわけではない。

## 実装の検証

320 / 375 / 390 / 430 / 768 / 1024 / 1440pxの7サイズで、各7カルーセルを確認した。

- 画像48点の読み込み失敗0件、JavaScript例外0件、ページ全体の横はみ出し0件。
- 最初のカード右端に影の5px以上の余裕がある。
- SPでは次カードの一部が見える。
- 全カルーセルで末尾への到達と次ボタンの無効化を確認。
