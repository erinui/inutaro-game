## ゲームの確定内容

- `FIX-INITIAL`、`FIX-CLEAR`、`FIX-HAZARD`を別に記録。基準値は設計書D-GAME-FIXと`fixtures.json`を参照。PC/SPの乱数seedは異なるが、表示する合計・内訳とhazardの12.4秒が一致する。両環境で繰り返して再現した。実際の終了時刻まで同一ではない。
- G03は3秒地点・ジャンプ中。G04/G06/G08/G09は26匹（17/9/0）、G05/G07は8匹（5/2/1）。hazardは949msでは待機中、950msで「けっかへ」が表示されることを確認した。
- G06/G07は結果パネル先頭、G08/G09は開いた操作部を表示したスクロール位置。説明・結果パネルの末尾はQA専用PNGとして保存した。
- 背景ぼかしがPDFで落ちる差を補正した。Canvasとぼかし背景は画像、文字・ボタンの見た目は輪郭・図形。縦持ちの印刷縮小はCanvas行列から実寸へ復元した。サイトのCSSは変更していない。

- 文字はアウトラインであり、FigmaのTEXTとして直接書き換えられない。文言を変更する場合は、原文・再描画・該当フレームの更新を行う。

- 長いH1のSP改行、パネル内スクロールによる見切れなど、現行実装由来の表示を保持。再現作業中にリデザインしない。
- 実機Safari、OS共有画面、実SNS投稿、保存ダイアログ、safe-area、音声再生、動作するFigmaプロトタイプは未検証または対象外。ブラウザ操作の網羅的なゲーム回帰テストを実施したという意味ではない。
- ソース19ファイルは設計時基準とのSHA-256一致を再確認。既存TOPのrootId・名前・ロック状態も一致。書き込み処理は新規ページ内の作成IDに限定した。
